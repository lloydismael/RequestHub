Connection setup

Local development

  1. Sign in with az login on the machine running Request Hub. Use an account with Monitoring Reader on each resource you want to monitor.
  2. Set AZURE_MONITOR_AUTH_MODE=azure_cli and the corresponding full Azure resource IDs in your local .env.

Azure App Service

  1. In App Service → Identity, turn on System assigned. Grant that identity Monitoring Reader on each monitored resource.
  2. Use the default managed_identity mode and set the full resource IDs in App Service settings.

Restart Request Hub after updating settings. Compare the reported sample times and values with Azure Monitor. A SQL connection alone cannot provide server CPU or disk metrics.
